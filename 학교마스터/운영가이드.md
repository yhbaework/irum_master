# UNIV_MASTER_M_BASE 연간 최신화 운영 가이드

## 작업 안내

대학알리미에서 매년 공개하는 원본 파일(학과정보·학교개황)을 가공해서,
DB 테이블 `UNIV_MASTER_M_BASE`에 적재할 CSV 파일을 만드는 작업입니다.

- 실행 스크립트: `build_UNIV_MASTER_M_BASE_당해연도.py`
- 결과물: `가공/UNIV_MASTER_M_BASE_<연도>.csv` (UTF-8 BOM)
- 작업 주기: 연 1회 이상. 원본이 새로 공개될 때마다 다시 실행하면 됩니다.

만들어진 CSV를 DB에 적재하는 작업은 이 문서에서 다루지 않습니다.

이 문서는 **매년 반복하는 최신화 작업**만 안내합니다.
2021~2026년 과거 자료를 한꺼번에 구축했던 1회성 작업 내용은
`작업기록_2021-2026.md`에 따로 정리되어 있으며, 평소 작업에는 필요하지 않습니다.

## 1. 실행 방법

### 1) 연도 폴더에 원본 넣기

작업 폴더 안에 4자리 연도 폴더를 만들고, 그 해 원본 파일을 넣습니다.

원본은 대학알리미 자료실에서 내려받습니다. 공개 시기는 해마다 다릅니다.

- 학교개황 > `학교 개황 정보(yyyy.MM.dd.기준)`
- 학과정보 > `YYYY년 상반기/하반기 기준 학부/과(전공) 리스트(yyyy.MM.dd.기준)`
- https://www.academyinfo.go.kr/brd/brd0520/selectListLink.do#1

내려받은 파일은 이름이 길고 형식도 제각각이므로, **아래 규칙에 맞게 이름을 바꿔서**
넣어 주세요.

```
학과정보_yyyyMMdd 기준.<확장자>
학교개황_yyyyMMdd 기준.<확장자>
```

`yyyyMMdd`에는 그 파일의 **자료기준일**을 적습니다. 확장자는 바꾸지 않습니다.

```
2025/
  학과정보_20250221 기준.xlsx     ← 상반기(조사차수 01)
  학과정보_20251002 기준.xlsx     ← 하반기(02)
  학교개황_20250507 기준.xls
  학교개황_20251002 기준.xls
  학교개황_20251121 기준.xls

2026/
  학과정보_20260219 기준.xlsx
  학교개황_20260722 기준.xlsx
  학교개황_20260828 기준.xls      ← 확장자가 섞여 있어도 됩니다
```

넣을 때 확인할 점

- **학과정보와 학교개황이 각각 최소 1개씩** 있어야 합니다.
  한쪽이라도 없으면 실행이 중단됩니다.
- 파일이 여러 개여도 됩니다. 합치는 방식은 아래 **2) 파일이 여러 개일 때**를 봐 주세요.
- **파일명의 기준일자로 어느 파일이 최신인지 판단**하므로 8자리 날짜를 꼭 넣어야
  합니다. 날짜를 찾지 못하면 실행이 중단됩니다.
- `.xlsx`와 `.xls`를 모두 읽습니다. 같은 해에 두 형식이 섞여 있어도 괜찮습니다.
- 파일 위쪽에 붙어 있는 자료기준일·안내문 줄은 자동으로 건너뜁니다.
  원본을 손대지 말고 그대로 넣어 주세요.

### 2) 파일이 여러 개일 때

#### 학과정보 — 상·하반기를 합치고, 하반기를 우선합니다

학과정보는 상반기(조사차수 `01`)와 하반기(`02`)가 따로 공개되므로 한 해에 2개가
될 수 있습니다. 두 파일을 합치되, **학교코드와 학과코드가 같으면 같은 학과로 보고
차수가 큰 쪽(하반기) 값을 채택**합니다. 하반기 파일에 없고 상반기에만 있는 학과는
그대로 남습니다.

```
    학과정보_20250221 기준.xlsx: 58,077행 (조사차수 01)
    학과정보_20251002 기준.xlsx: 58,796행 (조사차수 02)
    병합: 116,873행 -> 59,248행 (중복 57,625행은 최신 차수 채택)
    차수별 채택 행수: 01=452, 02=58,796
```

각 행의 `COL25 조사차수`를 보면 그 행이 어느 회차에서 왔는지 알 수 있습니다.
위 2025년 사례에서 452행은 상반기에만 있던 학과이고, 그중 370행은 학과상태가
`폐지`입니다. 하반기 파일에서는 빠졌지만 그해에 실재했던 학과이므로 마스터에 남깁니다.

> 학교코드와 학과코드 조합은 한 파일 안에서 중복되지 않습니다
> (2021~2026년 전 연도 확인, 중복 0건). 그래서 이 두 값으로 같은 학과인지 판단합니다.

#### 학교개황 — 나중 날짜 파일을 우선합니다

학교개황은 한 해에 여러 차례 공개될 수 있습니다. 파일을 모두 읽어 두고, 값을 찾을
때 **학교별로 기준일자가 가장 나중인 파일의 값을 먼저** 사용합니다.

- 두 파일에 모두 있는 학교 → **나중 파일의 값**을 사용
- 나중 파일에서 빠진 학교 → 이전 파일의 값으로 채움 (버리지 않습니다)

```
    학교개황_20250507 기준.xls: 2,111행 (기준일자 20250507)
    학교개황_20251002 기준.xls: 2,124행 (기준일자 20251002)
    학교개황_20251121 기준.xls: 2,141행 (기준일자 20251121)
    병합: 6,376행 (기준일자 20250507, 20251002, 20251121 — 나중 날짜 우선)
```

주로 폐교·신설 반영이 달라집니다. 실제로 2026년에 `20260828` 파일을 추가했더니
건국대학교(글로컬) 의학전문대학원과 상명대학교 문화기술대학원의 학교상태가
`기존`에서 `폐교`로 바뀌었습니다(8행).

**내려받은 학교개황은 지우지 말고 폴더에 함께 두세요.** 파일이 많을수록 정확해집니다.

### 3) 실행

폴더명을 생략하면 4자리 숫자 폴더 중 가장 최근 연도를 자동으로 사용합니다.

```
python build_UNIV_MASTER_M_BASE_당해연도.py
```

`setup.bat`을 실행하면 파이썬 가상환경(`irum_db`) 생성과 패키지 설치가 한 번에
진행됩니다. 이후 VS Code의 Python 인터프리터를 `irum_db`로 지정해 주세요.

필요한 패키지는 `requirements.txt`에 정리되어 있습니다.

| 패키지 | 용도 |
|---|---|

`pip install -r requirements.txt`를 다시 실행해 주세요.

## 2. 처리 흐름

```
학과정보 01·02 ─┐ 회차 병합(하반기 우선)
                ├─ 컬럼명 통일 → 결측 보완 → 테이블 형태로 변환 → CSV
학교개황 여러 개 ─┘ 기준일자 우선순위
```

1. **컬럼명 통일** — 해마다 달라지는 원본 컬럼명을 정해진 이름으로 바꿉니다
   (스크립트의 `학과_ALIAS`, `개황_ALIAS`)
2. **파일 병합** — 학과정보는 조사차수 기준, 학교개황은 기준일자 기준 (1절 참고)
3. **연도 확인** — 학과정보의 조사년도와 학교개황 파일명의 연도가 다르면 중단합니다
   (학교개황이 여러 개면 모두 같은 해여야 합니다)
4. **결측 보완** — 학과정보에 없는 값을 학교개황에서 찾아 채웁니다
5. **테이블 변환** — `tcm1002m.csv`의 정의대로 `COL1`~`COL55`, `CREATE_DT`,
   `MOD_DT` 형태로 만듭니다
6. **NOT NULL 점검** — 비어 있으면 안 되는 컬럼을 확인하고 문제가 있으면 알려 줍니다

## 3. 결측 보완 규칙

학과정보 원본에는 해마다 빠지는 컬럼이 있습니다(설립구분, 본분교 등).
이런 결측은 학교개황에서 찾아 채웁니다. **원본에 값이 있는 행은 그대로 두고,
결측인 행만** 채웁니다.

| 순서 | 무엇으로 찾는가 | 채우는 컬럼 |
|---|---|---|
| 1 | 학교코드 | 본분교, 설립구분, 학교상태 |
| 2 | 학교명 + 본분교 | 본분교, 설립구분, 학교상태 |
| 3 | **학교명 앞부분** (첫 띄어쓰기 앞) | **설립구분만** |
| 4 | 직접 지정한 값 | (현재 없음) |

1·2번은 그해 학교개황에 학교코드 컬럼이 있는지에 따라 자동으로 정해집니다
(2021년과 2026년 원본에는 학교코드 컬럼이 없었습니다).

학교개황이 여러 개면 **모든 순서에서 학교별 최신 기준일자 값을 사용**합니다.
같은 기준일자 안에서 값이 서로 다른 경우에만 판단이 불가능한 것으로 보고 건너뜁니다.

### 3번 — 학교명 앞부분으로 채우기

`강원대학교 산업대학원`에서 `강원대학교`처럼 **학교명의 첫 띄어쓰기 앞부분**으로
학교개황을 찾아 설립구분을 채웁니다. 같은 대학의 본교·분교·대학원은 설립구분이
같다는 점을 이용한 방법입니다.

이렇게 해도 되는 근거는 2021~2026년 전 연도를 확인한 결과입니다.
학교명 앞부분이 같은데 설립구분이 다른 사례가 **한 건도 없었습니다**
(2026년 기준 앞부분 418종, 설립구분이 2가지 이상인 경우 0종.
6년치 전체 325,071행을 연도 구분 없이 봐도, 연도별로 나눠 봐도 0건).
본교와 분교는 이 단계에서 이미 구분됩니다(`고려대학교`와 `고려대학교(세종)`).

값을 잘못 채우는 것보다 비워 두는 편이 안전하므로, 아래 경우에는 채우지 않습니다.

- 같은 앞부분인데 설립구분이 서로 다르면, 그 학교들은 전부 건너뜁니다.
- 1·2번에서 이미 채워진 값과 어긋나는 경우에도 건너뜁니다.

**이 방법은 설립구분에만 적용합니다.** 학교상태(폐교 여부)와 본분교는 같은 대학
안에서도 학교마다 다르므로 이렇게 채우면 안 됩니다.

### 잘못된 값이 들어가지 않도록 하는 장치

1·2번에서 **원본에 이미 있던 값과 학교개황의 값이 하나라도 다르면 실행을 중단**합니다.
찾는 기준이 잘못되었다는 뜻이므로, 그대로 진행하지 말고 원인을 확인해 주세요.

## 4. 원본 형식이 바뀌었을 때

원본은 해마다 시트 이름, 컬럼명, 컬럼 구성이 조금씩 바뀝니다.
대부분은 스크립트가 알아서 맞춰 읽으므로 손댈 것이 없습니다.

### 시트 이름이 바뀐 경우

**그대로 두세요.** 항상 첫 번째 시트를 읽습니다.
(지금까지 `학과`, `학과정보`, `sheet0`, `Sheet1`, `260220 1000기준 `, `empty`,
`학교개황(20251002 기준)` 등으로 제각각이었습니다)

### 파일 위에 안내문이 붙어 있는 경우

**그대로 두세요.** 컬럼명이 있는 행을 스스로 찾습니다.
2025년 학과정보처럼 위에 `자료기준일: 2025.02.21.`과 안내문(`※ …`), 빈 줄이
붙어 있어도 5번째 행의 컬럼명을 찾아 읽습니다. 건너뛴 줄 수를 화면에 표시합니다.

```
    (머리글 4행 건너뜀)   ← 학과정보(안내문 3줄 + 빈 줄)
    (머리글 1행 건너뜀)   ← 학교개황(자료기준일 1줄)
```

파일 위쪽 20행 안에서 아는 컬럼명을 3개 이상 찾지 못하면 실행이 중단됩니다.

### 파일 형식이 `.xls`인 경우

**그대로 두세요.** `.xlsx`와 `.xls`를 모두 읽습니다.
2025년 학교개황은 전부 `.xls`였고, 2026년은 `.xlsx`와 `.xls`가 섞여 있습니다.

### 컬럼명이 바뀐 경우 — 손봐야 합니다

모르는 컬럼명이 나오면 그 이름을 알려 주고 **실행을 중단**합니다.

```
매핑되지 않은 컬럼 ['주야간구분코드'] (학과정보_20270219 기준.xlsx)
  -> 스크립트 상단 ALIAS에 이 표기를 추가하세요.
```

이때는 `build_UNIV_MASTER_M_BASE_당해연도.py` 위쪽의 `학과_ALIAS` 또는 `개황_ALIAS`
목록에서 해당하는 항목을 찾아, 새 이름을 뒤에 추가하고 다시 실행해 주세요.

```python
"주야간구분": ["주야구분", "주야간구분", "주야간구분명", "주야간구분코드"],
```

지금까지 있었던 컬럼명 변경 사례입니다.

| 정해진 이름 | 연도별 원본 표기 |
|---|---|
| 대계열분류 | `표준분류대계열`(2021~2023) → `대계열분류`(2024~) |
| 주야간구분 | `주야구분` → `주야간구분` → `주야간구분명`(2026) |
| 지역 | `지역` → `(대학)지역` → `학교(지역)`(2026) |
| 대학자체대계열 | `대학자체대계열` → `대학자체5대계열`(2026) |
| 학과특성·학과상태·수업연한·학위과정 | 2026년부터 뒤에 `명`이 붙음 |
| 학교명(한자) | `중문학교명` → `학교명(한자)`(2023~) |
| 총장명 | `총장(대학원장)명` → `총장명`(2023~) |

컬럼명 안에 줄바꿈이 들어 있거나(`조사\n\n차수`) 엑셀 특수문자가 섞여 있어도
(`학교대표_x000D_\n번호`) 공백과 줄바꿈을 지우고 비교하므로 문제없습니다.

### 컬럼이 통째로 없어진 경우

**그대로 두세요.** 그 컬럼을 결측으로 두고, 어떤 컬럼이 없었는지 알려 줍니다.

```
원본에 없는 컬럼: ['설립구분', '단과대학코드']
```

설립구분·본분교·학교상태는 3절의 규칙으로 채워집니다.
그 밖의 컬럼은 비게 되므로, 화면에 나온 컬럼명을 보고 영향이 있는지 확인해 주세요.

## 5. 실행이 끝나면 확인할 것

### NOT NULL 점검 결과

```
[NOT NULL 컬럼 점검]
  COL1       공시연도      OK
  COL3       학교        OK
  COL4       본분교       OK
  COL11      단과대학      OK
  COL13      학과_전공     OK
  CREATE_DT  생성일자      건너뜀 (DB 적재 시 자동 입력)
  MOD_DT     수정일자      건너뜀 (DB 적재 시 자동 입력)
```

NOT NULL 컬럼입니다. **전부 `OK`여야 적재할 수 있습니다.**
하나라도 비어 있으면 마지막 줄에 경고가 표시됩니다.

`CREATE_DT`와 `MOD_DT`는 DB에서 자동으로 채워지므로 점검 대상에서 제외합니다.

### 잔여 결측 경고

```
! 잔여 결측 90행 / 학교 3개: ['강원대학교 교육대학원', ...]
```

NOT NULL 컬럼이 아니라 적재 자체는 가능합니다.
다만 **학교 수가 예년보다 눈에 띄게 늘었다면** 원본이나 보완 규칙에 문제가 생긴
신호일 수 있으니 확인해 주세요.

  자동 입력되기 때문입니다.
