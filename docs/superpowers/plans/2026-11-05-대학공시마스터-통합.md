# 대학공시 마스터 통합 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 학교마스터·지침서 두 스크립트를 연도 폴더 안에서 실행하는 스크립트 하나로 합치고, 실행 환경·폴더·가이드를 그에 맞게 정리한다.

**Architecture:** 스크립트 파일 하나(`DB build 마스터.py`)에 [공통 실행부] / [학교마스터] / [지침서] 세 구역을 둔다. 계산 코드는 기존 두 스크립트에서 그대로 옮기고, 파일 찾기·연도 결정·결과 경로·실행 순서만 새로 짠다. 스크립트는 자기 파일이 있는 폴더를 연도 폴더로 보고 `os.chdir`한 뒤 상대 경로로 일한다.

**Tech Stack:** Python 3.14, pandas, openpyxl, xlrd, pdfplumber, Windows `setup.bat`

**Spec:** `docs/superpowers/specs/2026-11-05-대학공시마스터-통합-design.md`

## Global Constraints

- 계산 결과(CSV 내용)는 기존 두 스크립트와 바이트 단위로 같아야 한다. 추출·병합·보완·NOT NULL 규칙은 고치지 않는다.
- 테스트 코드는 만들지 않는다(사용자 결정). 각 Task의 검증은 실행 명령과 결과 비교로 한다.
- 결과물: 연도 폴더의 `EXPORT/Univ_master_m_base_<yyMMdd>_<연도>.csv`, `EXPORT/Tcm1004m_<yyMMdd>_<연도>.csv` (`<yyMMdd>` = 실행한 날, 6자리)
- 원본 파일명: `학과정보_yyyyMMdd.<xlsx|xls>`, `학교개황_yyyyMMdd.<xlsx|xls>` — 기준일자는 밑줄 뒤 8자리.
- 하위 폴더 이름 고정: `정보공시지침서/`, `학과정보/`, `학교개황/`, `EXPORT/`. 컬럼 정의 파일: 연도 폴더 바로 아래 `마스터_컬럼정의.csv`.
- 가상환경: 작업환경 최상위 `irum_master/`. `requirements.txt`는 `pandas`, `openpyxl`, `xlrd`, `pdfplumber`만.
- `.gitignore`: `irum_master/`, `EXPORT/`.
- `tcm1001m.csv` 대조 기능은 없앤다.
- 기본폴더 이름: `(본 폴더를 복제한 다음 작업연도별 폴더를 생성하여 사용하세요)` (이하 `$TPL`).

- [ ] **Step 1: 지침서 구역 옮기기**

`정보공시지침서/build_tcm1004m_당해연도.py`의 49~526행(컬럼 ~ `_목록출력`)을 그대로 옮긴다. 바꿀 것만:

- [ ] **Step 2: `지침서_만들기(연도, 날짜)`**

기존 `처리(pdf)`가 바탕이다. 순서와 차이:
1. **PDF를 찾기 전에** `기존 = 기존_지침서_결과(연도)`. 있으면 아래를 출력하고 `None`을 돌려준다.
   ```
     지침서 결과가 이미 있어 건너뜁니다: {', '.join(os.path.basename(f) for f in 기존)}
     다시 만들려면 기존 파일을 지우거나 EXPORT 밖으로 옮기세요.
   ```
